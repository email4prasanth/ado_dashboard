## UI variation

Azure DevOps changes its interface periodically. If a label in this runbook differs slightly:

1. Confirm that you are using Azure DevOps Services, not an on-premises Server article.
2. Confirm the organization and process.
3. Match the operation by purpose.
4. Do not substitute a different rule action merely because the expected one is unavailable.
5. Record the screen and stop that specific rule if the required condition/action does not exist.
