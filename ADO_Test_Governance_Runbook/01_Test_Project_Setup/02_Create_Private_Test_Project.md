# Create the Private Test Project

## Checkpoint

Confirm:

```text
Organization: inlai-projects
Process available: Scrum Hybrid Governance
```

## Procedure

1. Select the Azure DevOps logo to open the organization Projects page.
2. Select **New project**.
3. Enter:

```text
Project name: Scrum-Governance-Test
Description: Isolated manual proof of concept for Scrum Hybrid Governance.
Visibility: Private
Version control: Git
Work item process: Scrum Hybrid Governance
```

4. If the process selector is under **Advanced**, expand Advanced and select it there.
5. Select **Create**.
6. Open **Project settings → Overview**.
7. Confirm the project name and visibility.
8. Open **Organization settings → Process → Scrum Hybrid Governance → Projects**.
9. Confirm that only `Scrum-Governance-Test` is listed.
10. Capture a screenshot.

## Do not do this

- Do not change the process of an existing project.
- Do not import or clone a production repository.
- Do not create a service connection.
- Do not copy a production pipeline.
